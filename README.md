# AI Code Analysis False Positives

This example demonstrates several Python code patterns that are perfectly valid, readable, and sometimes intentionally structured for clarity or future extensibility. It highlights how an overly strict or naive AI code analysis tool might mistakenly flag such good code as problematic, illustrating the 'false positive' problem discussed in the article. The code contains common constructs that could trigger warnings like 'redundant conditional', 'unused variable', or 'empty block' from an AI, even though they are acceptable or even preferred in certain development contexts.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal using `python main.py`.
